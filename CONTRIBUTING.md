# Contributing to CrawlAI Protocol ($CRAWL)

We welcome contributions from developers, researchers, and DePIN enthusiasts across the world!

## How to Get Started

1. **Check Open Issues**: Look at our [open issues](https://github.com/Synxneuos/crawlai/issues) tagged `good first issue` or `bounty-ready`.
2. **Fork & Branch**: Create a feature branch: `git checkout -b feat/your-feature-name`.
3. **Run Tests**: Ensure all protocol tests pass:
   ```bash
   npm test
   ```
4. **Submit PR**: Open a Pull Request referencing the issue number.

## Code Standards
- Keep core routing code dependency-light.
- Document all smart contract instructions and events.
- Add unit tests under `tests/` for any new proxy adapter or crawling engine.
